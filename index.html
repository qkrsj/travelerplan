이동 줄 교통수단:
이렇게 적어요
  • 날짜 줄: 1일차 메모
  • 장소 이벤트: 10:30 올드 트래포드 / 메모
  • 이동 이벤트: 10:15~10:45 피카딜리역 > 올드 트래포드 : 트램
  • 바로 앞 이벤트 위치에서 출발하려면 출발지를 빼도 돼요: 11:00 > 안필드 : 버스
  • 교통수단: 비행기, 기차, 지하철, 트램, 버스, 도보, 택시, 배
  • 사전에 없는 장소는 자동으로 온라인 검색해요(인터넷 필요, 한 번 찾으면 저장돼요). 못 찾거나 엉뚱한 곳이 잡히면 주소를 직접 적어요: 내 숙소@Piccadilly Gardens, Manchester (영문 주소가 잘 찾아져요).
  • 시간과 교통수단은 빼도 돼요. 교통수단을 빼면 거리로 추정해요.
  • 시간은 10:30, 10시 30분, 오후 3시, 3시 반, 10:00~11:30처럼 편하게 적어요.
  • 교통수단은 : 버스 대신 끝에 붙여도 돼요: 피카딜리역 > 안필드 버스, 피카딜리역 > 안필드 🚌
  • 날짜 번호를 세기 귀찮으면 다음날 제목으로 적어요.
  • 여러 곳을 한 줄로: A > B > C : 버스. 줄 앞의 -, *는 무시해요.
  • 다른 곳(메모장·노션·ChatGPT 등)에서 복사한 일정을 붙여넣으면 Day 1, 1월 14일, - 10:00 인천공항 → 서울 (버스, 30분) 같은 형태를 자동으로 양식에 맞춰요. 원본 그대로 넣으려면 Ctrl+Shift+V, 이미 붙여넣은 글은 🪄 양식 정리 버튼으로 고쳐요.
  • 위쪽 ＋ 일차 / 장소 / 이동 버튼은 커서 아래에 새 줄을 넣어 줘요(앞 줄의 끝 시간이 자동으로 들어가요). 이모지 버튼은 커서가 있는 이동 줄의 교통수단을 바꿔요.
  • 맨 끝에서 쓰던 중이면, 일차를 다 쓰고 빈 줄에서 Enter를 한 번 더 누르면 다음 일차(N일차 )가 자동으로 이어져요.
  • #로 시작하는 줄은 메모예요.

이벤트를 누르면 캐릭터가 지금 위치에서 그 이벤트까지 이동해요. 여러 칸 건너뛰면 중간 이동을 빠르게 지나가요. 도보·버스·택시·트램은 실제 도로를 따라가요(경로를 불러오는 동안이나 불러오지 못했을 때는 곡선). 비행기·기차·지하철·배는 두 장소를 잇는 곡선으로 움직여요.
